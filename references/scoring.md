# 评分公式与统计量（scoring）

元真的 AI 腔评分（0-100）由「规则分」与「统计分」合成，越高越像 AI 写的。

## 规则分（pattern_score，0-100）

```
加权命中密度 = Σ(规则权重 × 该规则命中次数) / 字数 × 100
密度分       = min(log2(密度 + 1) × 14, 60)     # 密度越高分越高，对数压顶
种类广度     = min(命中规则数 × 2, 20)           # 命中的规则类型越多越可疑
分组多样性   = min(命中分组数 × 4, 16)           # 五组中命中越多组越可疑
规则分       = min(密度分 + 种类广度 + 分组多样性, 100)
```

## 统计分（stats_score，0-100）

中文统计量（字数 / 句数过少时不参与，避免小样本误判）：

| 统计量 | 计算 | 说明 |
|---|---|---|
| 平均句长 | 每句 CJK 字数 + 数字/英文单词数 的均值 | 过长 > 30 字偏「书面腔」 |
| 句长波动 CV | 句长标准差 / 均值 | 低（< 0.25）= 句长均匀，AI 味 |
| 突发性 | 相邻句长差的均值 / 平均句长 | 低（< 0.3）= 节奏单调，AI 味 |
| 词汇多样性 | 连续双字（bigram）的 type-token ratio | 低（< 0.4）= 用词重复 |
| 逗号密度 | 每 100 字逗号数 | > 12 = 一逗到底 |

统计分合成（仅当字数 ≥ 40 且句数 ≥ 3）：

```
均匀度分量 u = clamp((0.5 - CV) / 0.35, 0, 1)
突发性分量 b = clamp((0.6 - 突发性) / 0.5, 0, 1)
多样性分量 t = clamp((0.6 - TTR) / 0.35, 0, 1)
统计分       = round(100 × (0.4u + 0.35b + 0.25t))
```

## 综合评分（0-100）

```
若 规则分 = 0 且 统计分 = 0 → 0
若 无规则命中           → min(round(统计分 × 0.12), 12)   # 统计量单独不指控
否则                    → min(round(规则分 × 0.7 + 统计分 × 0.3), 100)
```

评分档位：≥ 70 明显 AI 腔；45-69 中度 AI 腔；20-44 轻度 AI 痕迹；< 20 基本像人写的。

## 退出码（与元安 / 元审 / 元盾家族一致）

- 0 = 成功（评分低于阈值，或未启用 --gate）；
- 1 = score --gate 且评分 ≥ --threshold（默认 45，可 --threshold 调整）；
- 4 = 用法错误 / 致命异常。
