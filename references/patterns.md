# 24 类检测规则目录（patterns）

元真的检测规则按「内容 / 语言 / 句式 / 沟通 / 废话」五组组织，每条规则含词表与句式正则。命中即产出 finding（规则号 / 名称 / 权重 / 上下文片段 / 建议）。

权重含义：5 = 一眼 AI（强烈信号）；4 = 明显 AI 腔；3 = 有 AI 痕迹；2 = 轻微（需结合上下文判断）。

## 检测逻辑

- 每条规则 = 词表（原样匹配）+ 句式正则（re 编译），命中记录「匹配词 / 上下文片段」；
- 同一位置多条词命中会各自计入（如「标志着新时代的到来，意义重大」同时命中 HZ-01 的多个词）；
- 统计突发性见 scoring.md，与规则命中共同合成 0-100 评分。
